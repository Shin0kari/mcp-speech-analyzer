# Проверка Codex: 28 октября 2026

## Итог этапа 1

Проверен резервный путь: отдельный процесс `codex app-server --stdio` → JSONL → GPT-6.1 Terra. Подключение к общему control socket не работает в проведённых проверках; причина не установлена. Интеграция с существующим desktop-чатом не подтверждена. Это исследование подключения, а не готовое приложение захвата речи.

- ОЗУ: 16 828 727 296 байт, примерно 15,7 ГиБ.
- GPU по WMI: Intel Iris Xe и NVIDIA GeForce RTX 3070 Ti Laptop GPU. Показатель WMI AdapterRAM недостаточен для определения реального объёма VRAM.
- Команда `python` в ограниченной среде указывает на недоступный WindowsApps alias. Рабочий Python вне среды пока не проверен.

## Решение для следующего этапа

Использовать адаптер к отдельному app-server через stdin/stdout и собственную панель. Хранить thread ID и явно передавать пользовательский контекст. Автоматическое наследование контекста текущего desktop-чата не подтверждено.

Фоновые результаты сохранять в приложении без показа в его чате. Появляются ли такие ходы в desktop UI — непроверенный вопрос: отдельный процесс не гарантирует невидимость в общем хранилище Codex.

Общий desktop-чат исследовать после обнаружения поддерживаемого endpoint, проверяя синхронизацию и конкуренцию на тестовом чате. Не использовать `codex queue` в активном пользовательском чате как диагностический обход.

## Непроверенные возможности

- Отображение отдельной сессии и фоновых ходов в desktop UI, синхронизация и конкуренция клиентов.
- Реальный control endpoint и причина ошибки 10050.
- Длительный контекст, compaction, восстановление после сбоев и идемпотентность повторов. Короткий тест с кодом этого не доказывает.
- Structured output по локальной схеме, промышленная обработка server requests и закрытие транспорта во время хода.
- Производительность локального STT на двух каналах, доступные CUDA/runtime и размер модели после бенчмарка.
- Process loopback на выбранном приложении, поведение дочерних процессов браузера и ограничения Windows.

## Повторение

Из корня проекта, Node.js 24 и `codex` в PATH:

```powershell
node scripts/probe-codex.mjs proxy
node scripts/probe-codex.mjs standalone
```

Эти проверки только читают протокол, не создают чаты и не вызывают модель. Сам запуск сервера может создавать служебные файлы Codex.

Следующая проверка создаёт отдельную постоянную тестовую сессию и делает два модельных запроса. Каждый запуск создаёт новую сессию и расходует лимиты Codex:

```powershell
node scripts/verify-codex-session.mjs
```

Скрипты отклоняют запрошенные сервером действия и завершают только собственный серверный процесс. Это диагностический клиент; восстановление транспорта и надёжный повтор хода требуют отдельной реализации.
